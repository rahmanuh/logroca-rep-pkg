# LogRoca Replication Package

We provide a replication package of our manuscript, "LogRoca: Revealing Root Causes of Failed Test Execution Logs with a Large Language Model"
Due to privacy and confidentiality, test execution logs, test cases, and requirements datasets are provided upon request.
In addition, since the survey page contains those artefacts, the survey page is not complete. We replace the artefacts with dummy files.

# Contents

| Directory | Description |
|---|---|
| literatures | List of literatures that are used as references. |
| survey_page | Survey page generator with its dummy supporting files. The dummy supporting files need to be replaced with actual experiment results. |
| scripts | Selected useful scripts to support the experiments. |
